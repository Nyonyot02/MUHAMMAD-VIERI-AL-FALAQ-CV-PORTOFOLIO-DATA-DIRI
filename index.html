DES · U1

K-Line Communication Module (PRLTR)

FTDIPC817 optocouplerK-LineESP32

Universal K-Line motorcycle ECU diagnostic interface, dimulai dari Honda 4-pin DLC dengan target dukungan multi-brand. Rangkaian menggunakan dua optocoupler PC817C untuk isolasi bidirectional K-Line, FTDI voltage-selectable (3.3V/5V), dan firmware ESP32 WROOM dual-core dengan Web SPA scanner UI.

  • Schematic isolasi K-Line dengan 2× PC817C + status LED
  • Firmware ESP32 FreeRTOS, WiFi AP + web scanner interface
  • Database profil ECU multi-brand (EcuProfiles.h) untuk auto-detection
  • Output mode selectable: Web / USB / Both
